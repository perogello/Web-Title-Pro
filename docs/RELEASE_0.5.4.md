- **Data:** клик по строке больше не меняет титр, даже при включённой Live-правке. Применение строк во вкладке **Live** работает как раньше.

## EN

- **Data:** clicking a row no longer changes the title, even with Live-edit enabled. Applying rows from **Live** still works as before.
