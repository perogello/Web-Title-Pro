# Web Title Pro 0.5.2

## 🇷🇺 RU

**Модуль Bitfocus Companion**
- Свой модуль Companion: кнопки с живой подсветкой эфира, переменные (output, выбранный титр и его поля, время таймеров) и готовые пресеты для каждого output, титра и таймера. Companion 3.5 и новее.
- Установка в Companion одной кнопкой: **Settings › Integrations › Bitfocus Companion module**. Модуль обновляется вместе с приложением.
- Companion на другом ПК: кнопка «Скачать» `.tgz` → в Companion *Modules › Import module package*. Если версия устареет, подключение в Companion подсветится предупреждением.

**Прочее**
- **Settings › Controls:** у каждой команды теперь точные значения полей Companion (модуль или Generic HTTP POST) с кнопками Copy.
- **Settings › Integrations:** пояснения спрятаны за кнопку «?».

## 🇬🇧 EN

**Bitfocus Companion module**
- Our own Companion module: buttons with live on-air feedback, variables (output, selected title and its fields, timer time) and ready-made presets for every output, title and timer. Companion 3.5+.
- One-click install into Companion: **Settings › Integrations › Bitfocus Companion module**. The module updates together with the app.
- Companion on another PC: "Download" the `.tgz` → Companion *Modules › Import module package*. An outdated copy shows a warning on the connection.

**Also**
- **Settings › Controls:** every command now lists the exact Companion field values (module or Generic HTTP POST) with Copy buttons.
- **Settings › Integrations:** explanations are tucked behind a "?" button.
