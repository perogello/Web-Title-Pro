# Web Title Pro 0.5.1

## 🇷🇺 RU

> **Как обновиться**
> - **Установлена 0.5.0** — обновится сама: Settings › System › «Check for updates» или по предложению при запуске.
> - **Portable 0.4.x** — на «Доступно обновление» нажмите **«Позже»**, один раз установите `WebTitlePro-Setup-0.5.1.exe` вручную и удалите старые `WebTitlePro*.exe`. Настройки, титры и плагины подхватятся автоматически.

**Что нового**
- Диалоги (несохранённый проект при закрытии и обновлении, подтверждения удаления, сброс) — в стиле приложения вместо системных окон Windows.
- «Сохранить» в вопросе при закрытии/обновлении теперь сохраняет проект и продолжает закрытие или обновление.
- Горячие клавиши Ctrl+S / Ctrl+Shift+S / Ctrl+O / Ctrl+N, в том числе на русской раскладке.
- Уведомления внизу экрана; в Settings › System можно выбрать: все, только ошибки или никакие.
- Recent: удалённый или перемещённый проект убирается из списка с понятным сообщением.
- Config: output переименовывается прямо в строке; привязка титров к output показана номерами #1, #2…
- Live: колонки таблицы сжимаются уже текста — текст переносится или обрезается, высота строк не меняется.
- Data: клик рядом с кнопкой ✎ больше не выводит строку в эфир.
- Заметки: исправлены цвет, заливка и размер текста; доступны и без источника данных.
- Таймеры: в выборе vMix-источника только GT-титры (.gtzip).
- Верхняя панель подстраивается под ширину окна, кнопки окна всегда видны.

**Если вы переходите с portable 0.4.x**, в этой версии также: установщик вместо portable (без прав администратора, надёжные обновления без дублей exe), выбор при удалении — только приложение или вместе с данными, понятные ошибки обновления и система плагинов в Settings › Plugins.

## 🇬🇧 EN

> **How to update**
> - **0.5.0 installed** — updates itself: Settings › System › "Check for updates", or accept the prompt on launch.
> - **Portable 0.4.x** — click **"Later"** on the update prompt, install `WebTitlePro-Setup-0.5.1.exe` once by hand and delete the old `WebTitlePro*.exe`. Settings, titles and plugins carry over automatically.

**What's new**
- Dialogs (unsaved project on close and update, delete confirmations, reset) are app-styled instead of native Windows boxes.
- "Save" in the close/update prompt now saves the project and carries on closing or updating.
- Ctrl+S / Ctrl+Shift+S / Ctrl+O / Ctrl+N shortcuts, including on the Russian layout.
- Bottom-of-screen notifications; choose all, errors only or none in Settings › System.
- Recent: a deleted or moved project is removed from the list with a clear message.
- Config: rename an output inline; title-to-output bindings are shown as #1, #2… markers.
- Live: table columns can be squeezed below their text — it wraps or is clipped, rows keep their height.
- Data: clicking next to the ✎ button no longer puts the row on air.
- Notes: text colour, fill and size fixed; available without a data source too.
- Timers: the vMix source list shows GT titles (.gtzip) only.
- The top bar adapts to the window width; window controls always stay visible.

**Coming from portable 0.4.x**, this version also brings: an installer instead of the portable exe (no admin rights, reliable updates, no duplicate exes), an uninstall choice — app only or app with data, clear update errors, and the plugin system in Settings › Plugins.
